# Saoirse companion

## Overview

Use the approved plush portrait on the connection panel and the Home Screen icon. Keep the connection state explicit in text. Stack the portrait and status when text needs more room.

## Colors

Warm cream and cocoa surfaces frame the plush portrait. Headset blue marks actions and selections. A black field surrounds live camera frames and photos. Red marks errors and live capture.

## Typography

Use iOS system text styles with Dynamic Type. Keep the large top-level navigation titles and use native tab bars, forms, sliders and menus.

## Layout

Use the 24-point inset on the control and camera screens. Wi-Fi, conversations and configuration use native grouped lists. Connection feedback honors Reduce Motion.

## Components

Use prominent buttons for Move head and Start live view, bordered buttons for Center and Take photo, and a 44-point minimum for sliders. The 4:3 viewfinder shows Live while receiving frames.
