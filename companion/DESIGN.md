# Saoirse companion

Carry Saoirse’s device face into a native iPhone app. A deep pine surface with two luminous eyes is the recognizable connection display. Open eyes indicate a reachable robot. A resting line indicates an offline or unpaired robot. The adjacent text always spells out the connection state.

Use system typography, tab bars, navigation, forms, sliders, menus and semantic text colors. Teal is the single action tint, with a lighter appearance in Dark Mode. Keep the camera view black so image content reads at its true exposure. Reserve red for errors or an active live camera.

Use one brief eye-shape transition on connection changes and honor Reduce Motion. Use the same 24-point content inset on control and camera screens. Wi-Fi, conversations and configuration are native inset lists.
